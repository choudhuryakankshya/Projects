# Computational Astrophysics Projects

A collection of Python-based astrophysics projects involving observational data analysis, numerical modelling, and physical parameter estimation.

## Projects

- **Dynamical Mass Estimation** — Estimation of galaxy cluster mass from the kinematics of member galaxies.
- **Hubble Parameter Estimation** — Measurement of $H_0$ and $\Omega_m$ using Type Ia supernovae from the Pantheon+SH0ES dataset.

**Tools:** Python · NumPy · Pandas · SciPy · Matplotlib · Astropy · Jupyter Notebook
